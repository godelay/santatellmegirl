# 오늘의 럭 아이템 + 스핑크스 고민 → 채팅 (11/18 메모)

> 집 컴퓨터에서 열었을 때 전체 기획에 반영할 추가 아이디어.
> 핵심: **스핑크스가 채팅에서 들은 말을 전부 기억하고, 그걸 데이터베이스에 쌓는다.**

---

## 1. 화면 흐름

```
┌───────────────────────────────┐
│  🍀 Today's Lucky Item          │
│  [ 은반지 이미지 ]               │
│  A silver ring                  │
│  Lucky color: Lavender · No. 7  │
├───────────────────────────────┤
│  🦁 Sphinx                      │
│  "Today feels like a day for    │
│   saying the thing you've been  │
│   holding in. Is there someone  │
│   on your mind?"                │
│                                 │
│  [ Actually, yes… ]  [ Tell me more ] │
└───────────────────────────────┘
            ↓ 버튼을 누르면
        💬 스핑크스 채팅으로 넘어감
```

1. **오늘의 럭 아이템:** 매일 바뀜. 내 차트 + 오늘 행성 위치로 정함 (같은 날 같은 사람 = 같은 아이템).
2. **스핑크스의 오늘의 고민:** 오늘 운세와 **내가 전에 했던 말(기억)** 을 섞어서 고민 하나를 뽑아 먼저 말을 검.
3. **채팅으로 넘어가기:** 버튼 두 개 다 채팅으로 이어짐. 답을 고르면 그 대답이 첫 메시지로 들어감.
4. 톤은 05번 노트와 같은 **좋게 좋게.** 운세가 나빠도 겁주지 않고 "오늘은 이렇게 하면 좋은 날".

## 2. 왜 이게 좋은가
- **매일 들어올 이유:** 궁합은 한 번 보면 끝 → 럭 아이템은 매일 바뀜 = 재방문.
- **스핑크스가 먼저 말을 건다:** 빈 채팅창은 뭘 쳐야 할지 모름. 고민을 먼저 던지면 대답하기 쉬움.
- **기억이 쌓일수록 나만의 스핑크스:** "지난주에 말한 이사, 잘 끝났어?" → 다른 운세 앱으로 못 옮겨감 (쌓인 기억이 자산).
- **궁합으로 연결:** 채팅에서 친구 이름(Mia)이 나오면 → "Mia랑 궁합 볼래요?" → 초대 → 친구 별 늘어남.

## 3. 기억하기 (핵심)

### 무엇을 기억하나
| 종류 | 예시 | 나중에 쓰는 곳 |
|---|---|---|
| 👤 사람 | Mia = 대학 룸메이트, 요즘 서운함 | 고민 뽑기, 궁합 추천 |
| 📅 일정 | 토요일 이사, 12월 친구 결혼식 | "이사 잘 끝났어?" 후속 질문 |
| 💭 고민 | 이직 고민, 연애 고민 | 오늘의 고민 뽑기 |
| ❤️ 취향 | 라벤더 좋아함, 아침형 | 럭 아이템 고르기 |
| 🎉 좋은 일 | 승진함, 새집 이사 | 축하 메시지 |

### 기억하는 방법
1. **채팅 원문을 전부 저장.** 지우지 않고 다 쌓아둠 (원본).
2. **메시지마다 기억 뽑기:** AI가 메시지에서 사람·일정·고민·취향을 뽑아 따로 저장.
3. **고민은 상태를 가짐:** 진행 중 → 해결됨. 해결되면 "잘 됐다니 기뻐요" 하고 그만 물어봄.
4. **대화 요약:** 대화가 끝나면 한 단락으로 요약해서 저장 (길어져도 빨리 불러오게).
5. **다음 대화 때 불러오기:** 오늘 고민·지금 대화와 관련 있는 기억 + 최근 기억을 골라서 스핑크스에게 줌.

### 데이터베이스 (초안)

| 테이블 | 담는 것 | 주요 칸 |
|---|---|---|
| `users` | 사용자 | id, 이름, 생일, 출생 시간·도시, 가입일 |
| `chat_sessions` | 대화 한 번 | id, user_id, 시작 시각, 시작 계기(오늘의 고민 id), 요약 |
| `messages` | **채팅 원문 전부** | id, session_id, user_id, 누가(사용자/스핑크스), 내용, 시각 |
| `memories` | 뽑아낸 기억 | id, user_id, 종류(사람/일정/고민/취향/좋은 일), 대상(예: Mia), 내용, 날짜(일정이면), 상태(진행 중/해결됨), 중요도, 원본 메시지 id, 만든 시각, 마지막으로 쓴 시각 |
| `people` | 채팅에 나온 사람 | id, user_id, 이름, 관계, 차트에 있는 친구면 그 친구 id |
| `daily_cards` | 매일 카드 | user_id, 날짜, 럭 아이템, 럭 컬러·숫자, 뽑은 고민(memory id 또는 운세 주제), 채팅으로 넘어갔는지 |

- `memories`에 **원본 메시지 id**를 남겨서 "왜 이걸 기억하는지" 언제든 확인 가능하게.
- `daily_cards`의 "채팅으로 넘어갔는지"로 **어떤 고민이 대화를 많이 여는지** 측정.

### 오늘의 고민 뽑는 규칙 (초안)
1. 날짜가 가까운 일정이 있으면 그것 먼저 ("이사가 이번 주네요").
2. 없으면 진행 중인 고민 중 오래 안 물어본 것.
3. 기억이 없는 새 사용자는 오늘 운세 주제로 ("Mercury is busy today — anything you've been meaning to say?").

## 4. 미국에서 조심할 것 (기억 기능이라 중요)
- **처음에 알리기:** "Sphinx remembers what you tell it, so every chat gets more personal." 를 채팅 시작 때 보여줌.
- **내 기억 보기·지우기 페이지:** "What Sphinx remembers about you" → 하나씩 지우기, 전부 지우기. (캘리포니아 등 주별 개인정보 법 대응)
- **데이터 안 팔기**, 광고에 안 쓰기를 약관에 명시.
- **13세 미만 가입 불가** (미국 아동 개인정보 법).
- **민감한 얘기(건강, 자해, 위기 상황):** 기억은 하되 고민 뽑기에 쓰지 않음. 위기 신호가 보이면 운세 말고 도움받을 곳(미국 988 위기 상담 전화)을 안내.
- 채팅에 나온 **친구의 이야기**도 저장되니까, 친구에게 공유되는 화면(랭킹·알림)에는 절대 안 씀.

## 5. 돈 버는 곳 (선택, 미정)
- 럭 아이템 + 오늘의 고민 = 무료 (매일 오게).
- 채팅: 하루 몇 마디 무료 → 더 하려면 쿠키.
- 또는 채팅에서 친구 이름이 나오면 궁합 쿠키로 연결 (기존 결제 흐름 재사용).
