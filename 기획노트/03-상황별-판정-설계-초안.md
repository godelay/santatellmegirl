## 2. 별점 계산 규칙 (행성 매칭)

상황마다 "그 상황에서 중요한 성향"을 맡은 행성 쌍을 본다.
두 사람 행성 사이 각도가 **조화(△ 삼각, ⚹ 육각)면 +**, **긴장(□ 사각, ☍ 충)이면 −**, **☌ 합은 행성에 따라 +/−**.

| 상황 | 보는 행성 쌍 | 이유 (화면에 쓸 수 있는 한 줄) |
|---|---|---|
| 💸 돈 | 금성–토성, 수성–토성, 태양–토성 | 금성=돈·가치, 토성=약속·책임. "갚겠다는 말을 지키는 궁합인지" |
| ✈️ 여행 | 화성–화성, 목성–태양, 달–달 | 화성=체력·페이스, 목성=모험, 달=편안함. "속도와 기분이 맞는지" |
| 🏠 같이 살기 | 달–달, 달–토성, 금성–금성 | 달=생활 습관, 토성=규칙, 금성=취향. "매일 부딪혀도 괜찮은지" |
| ~~💼 같이 일하기~~ (제외) | 태양–토성, 수성–수성, 화성–화성 | 태양=목표, 수성=소통, 화성=추진력. "같은 방향으로 밀어붙이는지" |
| 🤫 비밀 | 달–수성, 수성–토성, 수성–화성 | 달=감정, 수성=말, 토성=입 무거움, 화성=욱함. "말이 새는 궁합인지" |

### 별점이 들쭉날쭉하게 나오게 하는 장치 (중요)
- 점수를 그대로 별로 바꾸면 대부분 ★★★가 나와서 재미없음.
- **한 사람 쌍 안에서 5개 상황을 순위로 줄 세운 다음** 별을 나눠준다.
  - 1등 ★★★★★ 또는 ★★★★ / 꼴등 ★ 또는 ★★ / 나머지는 그 사이
  - → 누구랑 해도 "이건 최고, 이건 최악"이 반드시 생김 = 공유거리
- 절대 점수가 아주 높거나 낮은 쌍만 위아래로 조금 밀어준다 (찐 궁합은 전체가 높게).

### 출생 시간을 모를 때
- 달은 하루에 약 13° 움직여서, 시간을 모르면 달 각도가 틀릴 수 있음.
- 시간 모름 → 정오 기준으로 계산하고, 달이 들어간 판정에는 작게 "시간을 넣으면 더 정확해져요" 표시
  → 출생 시간 입력 유도도 됨.

## 3. 판정 문구

### 원칙
- 별점 구간마다 문구를 **여러 개** 준비해서 같은 별점이어도 사람마다 다르게.
- 좋은 말과 안 좋은 말을 섞는다. 나쁜 판정도 **웃기게**, 상처 주지 않게.
- 톤 결정 필요: astronote.me는 영어 → **영어 메인, 한국어판은 밈 톤**으로 따로?

### 💸 돈 빌려주기 예시

| 별점 | 한국어 | English |
|---|---|---|
| ★★★★★ | 보증도 서줄 사이 | You'd co-sign their lease |
| ★★★★ | 빌려줘도 이자까지 옴 | It comes back with snacks |
| ★★★ | 소액만, 날짜 박아서 | Small amounts, with a due date |
| ★★ | 돌려받으려면 세 번 말해야 함 | You'll be asking three times |
| ★ | 빌려주지 마 | Do. Not. Lend. |

### ✈️ 여행

| 별점 | 한국어 | English |
|---|---|---|
| ★★★★★ | 최고의 동행 | Your ultimate travel buddy |
| ★★★★ | 일정 안 맞아도 웃음 | Lost luggage, still laughing |
| ★★★ | 2박까지만 | Max two nights |
| ★★ | 셋째 날 각자 여행 | Day 3: separate itineraries |
| ★ | 공항에서 갈라짐 | Breakup at the airport |

### 🏠 같이 살기 · 🤫 비밀 (한 줄씩)
- 🏠 ★★★★★ 평생 룸메 / ★★★ 3개월이 고비 / ★ 계약 전에 다시 생각해
- 🤫 ★★★★★ 무덤까지 가져감 / ★★★ 반쯤만 말해 / ★ 내일 단톡방에 뜬다

## 4. 무료 / 유료(쿠키) 경계

| | 무료 | 쿠키 1개 |
|---|---|---|
| 조합 이름 + 한 줄 설명 | ✅ | |
| 5개 상황 별점 | ✅ 전부 | |
| 상황별 한 줄 판정 | ✅ 3~4개 | **🔒 1~2개** (가장 낮은 판정 + 가장 높은 판정 중 하나) |
| 판정 이유 (왜 이 별점인지) | | ✅ |
| 처방 ("그래도 빌려준다면 이렇게") | | ✅ |

- 잠그는 건 **가장 낮은 판정**이 기본 → "빌려주지 마"의 이유가 제일 궁금함 (01번 가설: 나쁘게 나오면 해결책을 원한다).
- 전부 잠그면 짜증, 하나만 잠그면 궁금함.
- 처방이 부적 역할: 나쁜 판정 → 해결책 → 결제.

## ✅ 최종 확정 (11/18): 한 화면 5개, 전부 고정

| 상황 | 쪽 | 넣은 이유 |
|---|---|---|
| 💸 돈 빌려주기 | 결제 | 결제 동기가 가장 강함 ("빌려주지 마"의 이유를 열고 싶어짐) |
| 🏠 같이 살기 | 결제 | 계약 같은 큰 결정 직전에 보고 싶은 궁합 |
| 💔 연애 상담 | 결제 | 연애 궁합으로 넘어가는 다리 |
| 💍 결혼식 들러리·축사 | 결제 | 날짜가 정해진 이벤트, 결혼 시즌 수요 |
| 🤫 비밀 털어놓기 | 공유 | 웃긴 판정이 잘 나옴 → 캡처·공유 |

- **"고정 4 + 돌려 쓰기 2" 안은 폐기.** 캡처를 비교할 때 혼란이 생기고 구조가 복잡해서, 5개를 전부 고정으로 보여주기로 함.
- 빠진 것: ✈️ 같이 여행 (11/18 제외), 🔑 집 비밀번호, 🍜 메뉴, 🛍️ 쇼핑
  - 🔑·🍜·🛍️·✈️는 나중에 시즌 이벤트나 랭킹 보너스 후보로 남겨둠 (미정)
- 위쪽 초안의 여행·같이 일하기 관련 문구와 행성 매칭은 참고용으로만 남겨둠.
- 아직 할 일: 💔 연애 상담, 💍 결혼식의 행성 매칭과 판정 문구
