# 상황별 궁합 라벨 아이디어 (11/17)

## 출발점
- 지금 궁합 이름: **골든리트리버 + 블랙캣** 같은 성격 조합 (관계의 "모양"을 보여줌)
- 새로 재밌어 보이는 것: **"돈 빌려줄 친구"** 같은 상황 판정 (그 관계로 "뭘 해도 되는지"를 보여줌)
- 둘은 경쟁이 아니라 층이 다르다 → **조합 이름은 그대로 두고, 그 밑에 상황별 판정을 붙인다.**

## 결과 화면 구성안

```
🐶 골든리트리버 + 🐈‍⬛ 블랙캣
"한쪽은 다 퍼주고, 한쪽은 다 기억한다"

✈️ 같이 여행       ★★★★☆  최고의 동행
🏠 같이 살기       ★★☆☆☆  3개월이 고비
💸 돈 빌려주기     ★☆☆☆☆  빌려주지 마 (이유는 🔒)
💼 같이 일하기     ★★★★★  역대급 파트너
🤫 비밀 털어놓기   ★★★☆☆  🔒
```

- 무료: 조합 이름 + 상황별 **별점과 한 줄 판정**
- 유료(쿠키): 판정의 **이유와 처방** ("왜 돈은 안 되는지, 그래도 빌려준다면 이렇게")
- 나쁜 판정이 곧 결제 포인트 → 가설 1의 "나쁘게 나와도 순응 안 하고 해결책을 원한다"와 연결

## 판정 문구 톤 예시
좋은 말과 안 좋은 말을 섞는다 (전부 좋으면 공유는 되지만 결제가 없고, 전부 나쁘면 이탈).

| 상황 | 좋을 때 | 애매할 때 | 나쁠 때 |
|---|---|---|---|
| 💸 돈 | 보증도 서줄 사이 | 소액만, 날짜 박아서 | 빌려주지 마 |
| ✈️ 여행 | 최고의 동행 | 2박까지만 | 공항에서 갈라짐 |
| 🏠 같이 살기 | 평생 룸메 | 3개월이 고비 | 계약 전에 다시 생각해 |
| 💼 같이 일하기 | 역대급 파트너 | 역할만 나누면 OK | 친구로 남는 게 나음 |
| 🤫 비밀 | 무덤까지 가져감 | 반쯤만 말해 | 내일 단톡방에 뜬다 |
| 💔 연애 상담 | 인생 상담사 | 들어만 줌 | 네 편 안 들어줌 |

## 왜 재밌나 (가설)
1. **공유하고 싶어진다:** "우리 돈 빌려주면 안 되는 사이래 ㅋㅋ" → 단톡방 캡처각. 조합 이름보다 대화거리가 됨.
2. **상대에게 물어보고 싶어진다:** 판정이 둘 다에게 해당 → 친구에게 "너도 넣어봐" 초대가 자연스러움 (지금 별 남기기 구조와 맞음).
3. **나쁜 판정이 궁금증을 만든다:** "빌려주지 마"의 이유는 잠가두면 결제 동기.
4. **가설 2 실험이 된다:** 어떤 상황 판정을 가장 많이 누르고 공유하는지 보면, 어떤 상황이 친구 궁합 수요를 키우는지 데이터가 나옴.

## 확장 아이디어
- **랭킹형:** 친구가 여러 명이면 "내 친구 중 돈 빌려줄 1위 / 여행 1위 / 비밀 1위" → 친구 10명 모으기(Patterns)의 보상으로 딱 맞음
- **상황 먼저 고르기:** 초대 링크를 "너랑 여행 궁합 보고 싶어"처럼 상황을 정해서 보낼 수 있게 → 관계 선택(Friends 등) 칸을 상황 선택으로 바꾸는 실험
