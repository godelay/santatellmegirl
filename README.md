# 스타 기획 프로젝트

새로 시작하는 기획 프로젝트입니다. 내용은 정해지는 대로 채워 넣습니다.

## 다른 컴퓨터에서 이어서 하기
1. 이 저장소를 받습니다: `git clone <저장소 주소>`
2. 그 폴더에서 Claude Code를 열고 "스타 기획 이어서 하자"라고 말합니다.
3. 작업이 끝나면 "깃허브에 올려줘"라고 하면 변경 내용을 올립니다.
